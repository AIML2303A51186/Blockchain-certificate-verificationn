
# Blockchain-Based Certificate Verification System

## Project Description
This project is developed using Python.
It uses blockchain technology and SHA-256 hashing
to verify student certificates.

## Technologies Used
- Python
- SHA-256 Hashing
- Blockchain
- JSON

## Features
1. Create blockchain.
2. Generate student certificates.
3. Generate unique certificate IDs.
4. Verify genuine certificates.
5. Detect fake certificates.
6. Detect blockchain tampering.

## How to Run

1. Install Python.
2. Download demo_blockchain.py.
3. Open Terminal in the project folder.
4. Run this command:

```bash
python demo_blockchain.py
```

## Expected Output
- Certificate ID: Unique hash
- Genuine cert: True
- Fake cert: False
- Chain valid: True
- After tampering: False
